# Fragmas

Sitio web personal de la marca Fragmas — Flor Maldonado.

Construido con [Vite](https://vitejs.dev/) + [React](https://react.dev/). Diseño editorial con Cormorant Garamond, paleta crudo/azul-lago.

## Sub-marcas

- **Escritura** — Flor Maldonado, autora
- **Streaming** — HormigaViajera en Twitch
- **Diseño** — Flucty

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
